# 제조데이터 제출 검증 도구

M.AX 얼라이언스에 제출할 **제조 데이터의 형식을 검사하고, 제출 파일을 생성해 주는** Windows 프로그램입니다.

제출 데이터 폴더를 선택하고 화면에 데이터 정보를 입력하면, 빠진 항목이나 잘못된 파일이 없는지 검사합니다. 검사를 통과하면 제출에 필요한 파일을 데이터 폴더 안 `metadata` 폴더에 자동으로 생성됩니다.

- **`<데이터셋 ID>.jsonld`** — 메타데이터(데이터 설명서). 국제 표준 형식([Croissant](https://mlcommons.org/croissant/1.1))으로 저장됩니다.
- **`제조데이터검증확인서.pdf`** — 검사를 통과했다는 확인서
- **`<데이터셋 ID>.xlsx`** — 입력한 내용과 실제 파일 수·용량을 한 줄로 정리한 요약 엑셀

## 사용 방법

1. **설치** — [다운로드](#다운로드)에서 받은 `metadata_validator-Setup-<버전>.exe`를 실행합니다.
2. **데이터 폴더 준비** — 아래 [데이터 폴더 준비](#데이터-폴더-준비)대로 폴더를 정리합니다.
3. **프로젝트 불러오기** — 데이터가 들어 있는 폴더를 선택합니다.
4. **내용 입력** — 두 가지 방법 중 편한 쪽을 쓰세요.
   - **엑셀로 작성**: [엑셀 양식](#엑셀-양식으로-작성하기)을 채운 뒤 **엑셀 업로드**를 누릅니다. 모든 탭이 한 번에 채워집니다.
   - **화면에서 직접**: 아래쪽 탭 5개(기본정보 · 데이터 정보 · 라벨 정보 · 데이터 스플릿 정보 · AI 모델 정보)를 차례로 작성합니다.
5. **검증 실행** — 로그창에 오류(빨간색 표시)가 없어질 때까지 수정합니다.
6. **메타데이터 변환** — 제출 파일 세 개가 데이터 폴더 안 `metadata` 폴더에 저장됩니다.

## 데이터 폴더 준비

제출할 제조 데이터 폴더 안에 아래 **4개 폴더가 모두** 있어야 합니다.

```
내 데이터 폴더/
├── raw/            원본 데이터
├── processed/      학습용으로 정리한 데이터
│   ├── train/      학습용 (필수)
│   ├── validation/ 검증용 (선택)
│   └── test/       평가용 (필수)
├── annotations/    라벨 파일
├── AImodel/        학습한 AI 모델
└── metadata/       ← '메타데이터 변환' 시 자동 생성 (.jsonld · 확인서 PDF · 요약 엑셀)
```

- 입력 화면의 '데이터 경로'에는 이 폴더 기준으로 `./processed`, `./annotations`을 작성합니다.
- (중요) CSV, Excel 같은 Tabular 데이터를 제출하는 경우, 파일내 **첫 행(Row)은 열(Column) 이름**이어야 합니다.

## 데이터 입력 참고사항

- **`*` 표시**가 있는 항목은 꼭 채워야 합니다. 각 항목의 **비고** 칸에 작성 예시가 있습니다.
- **데이터셋 ID**는 영문·숫자·`-`·`_`·`.`만 쓸 수 있습니다. (예: `MAX_SECOM_DS01`)
- **대상 업종·공정**은 업종을 먼저 고른 뒤 공정을 고릅니다. 1~5개까지 고를 수 있습니다.
- **소재 지역**(대상 기업 · 제출 기관)은 목록에서 고릅니다(예: `경기 수원`, `대전`). 엑셀 양식도 드롭다운이며, 예전 양식의 `경기도 수원시` 같은 값은 엑셀 업로드 때 목록 값으로 맞춰 줍니다.
- **데이터 유형**은 현재 Image, Tabular(표), Time Series(시계열), 3D Point Cloud, Text 다섯 가지를 지원합니다.
- **여러 탭에 같은 항목**이 있습니다 — '데이터 유형'(기본정보 · 데이터 정보 · AI 모델 정보의 '입력 데이터'), 'AI Task 유형'(기본정보 · AI 모델 정보), '샘플링 주기'(데이터 정보 · AI 모델 정보). **탭마다 같은 값**이어야 하며, 다르면 오류로 변환되지 않습니다.
- **Time Series**를 고르면 **샘플링 주기**(샘플 1개를 이루는 연속 데이터 행 수, 정수) 칸이 나타나며 필수입니다. (예: `10` → 같은 파일의 연속 10행이 AI 입력 1개)
  시계열은 두 가지 형태로 받습니다 — ① 표 안에 시점별 라벨 열이 있는 CSV(`column`), ② 클래스 이름 폴더에 나눈 파일(`folder`). 파일은 CSV(쉼표 구분 권장)로 냅니다.
- **Tabular 데이터**는 '입력(Feature) 컬럼'에 학습에 쓸 컬럼을 엑셀 셀 주소로 적습니다. (예: `B1:VS1`)
- **스플릿 비율**은 0~1 사이 숫자로, 합이 1이 되게 적습니다. (예: 학습 0.8, 테스트 0.2)
- **데이터-라벨 매핑 기준**(필수)은 라벨이 어디에 있는지에 따라 고릅니다. 항목 옆 **?** 를 누르면 그림으로 된 설명이 오른쪽에 열립니다. 비어 있으면 메타데이터 변환이 되지 않습니다.

  | 선택 | 이럴 때 | 예시 |
  |------|---------|------|
  | `column` | 라벨이 데이터 표 안의 한 컬럼일 때 | CSV의 `Pass/Fail` 컬럼 |
  | `filename` | 데이터 파일과 라벨 파일의 이름이 같을 때 | `a.jpg` ↔ `a.txt` |
  | `id/key` | 데이터 표와 라벨 표가 따로 있고, 같은 ID 컬럼으로 연결될 때 | 두 표 모두 `id` 컬럼 |
  | `index` | 순서로만 짝이 맞을 때 (1번째 ↔ 1번째) | 순서대로 저장된 데이터·라벨 |
  | `folder` | 클래스별로 폴더를 나눴을 때 — 폴더 이름이 라벨 (Tabular 제외) | `train/정상/a.csv`, `train/불량/b.jpg` |
  | `unsupervised` | 라벨이 없을 때 (비지도 학습) | 정상 데이터만 모은 이상 탐지용 이미지 |

  `column`이나 `id/key`를 고르면 '라벨 컬럼'에 실제 컬럼 이름을 정확히 적어야 합니다.
  `column`을 고르면 라벨 정보의 데이터 경로·파일 패턴 칸이 사라집니다(라벨이 데이터 파일 안에 있으므로 데이터 정보 값을 씀).
  `folder`를 고르면 라벨 경로·파일 패턴·라벨 컬럼 칸은 사라지고, '클래스 분류'에 **폴더 이름을 그대로** 적습니다(예: `정상, 불량`, 값을 붙이려면 `1: Pass, -1: Fail` — 콜론 뒤가 폴더 이름이고 대소문자까지 같아야 함). 적은 클래스의 폴더가 스플릿마다 없거나 비어 있으면 오류입니다.
  `unsupervised`를 고르면 매핑 기준 외의 라벨 칸이 모두 사라집니다. 이때 AI Task가 Classification·Object Detection·Segmentation·Pose Estimation·OCR처럼 라벨이 꼭 필요한 유형이면 오류입니다.

## 엑셀 양식으로 작성하기

1. 양식을 내려받습니다: **[제출 양식 (template.xlsx)](template.xlsx)**
   작성 예시: [MAX_SECOM_DS01.xlsx](samples/MAX_SECOM_DS01/MAX_SECOM_DS01.xlsx) (표 데이터) · [MAX_TR_DS01.xlsx](samples/MAX_TR_DS01/MAX_TR_DS01.xlsx) (이미지 데이터)
2. 시트마다 **'입력'(D열)** 칸을 채웁니다. 화면과 같은 칸은 드롭다운으로 고를 수 있습니다.
   - **대상 업종**을 고르면 **대상 공정** 드롭다운에 그 업종의 공정만 나옵니다.
   - 공정을 여러 개(최대 5개) 쓰려면 쉼표로 이어서 입력합니다. "목록에 없는 값" 경고가 뜨면 **예**를 누르세요.
   - 다른 업종의 공정은 `업종·공정 목록` 시트의 C열 값을 복사해 붙입니다.
3. 프로그램에서 **엑셀 업로드**를 누르고 파일을 고릅니다.
4. 로그창에 노란 글씨가 있으면 확인합니다. 목록에 없는 값은 비워 두거나 빼고 알려 줍니다.

## 검증 결과 확인

**검증 실행**을 누르면 결과가 아래쪽 로그창에 나옵니다.

- **빨간 글씨(오류)**: 고쳐야 제출 파일이 만들어집니다. 문제가 있는 칸도 빨갛게 표시됩니다.
- **노란 글씨(경고)**: 제출 파일은 만들어지지만, 한 번 확인해 보세요.

자주 나오는 오류:

| 오류 | 고치는 방법 |
|------|------------|
| 필수 폴더 누락 | 데이터 폴더에 `raw`, `processed`, `annotations`, `AImodel` 폴더를 만듭니다. |
| 파일이 없습니다 | 데이터 경로와 스플릿 폴더(`train`, `test`)에 파일이 있는지, 파일 패턴(`*.csv` 등)이 맞는지 확인합니다. |
| 필수 항목입니다 | `*` 표시 항목을 채웁니다. 아래 탭의 노란 점이 미완료 시트입니다. |
| 라벨 컬럼이 헤더에 없습니다 | '라벨 컬럼'을 CSV 첫 줄의 컬럼 이름과 똑같이 적습니다. |
| 라벨 값이 선언한 클래스와 다릅니다 | '클래스 분류'에 실제 데이터의 라벨 값을 모두 적습니다. (예: `-1 : Pass`, `1 : Fail`) |
| 비율이 숫자가 아닙니다 | 스플릿 비율을 `0.8`처럼 숫자로 적습니다. |

## 제출 파일

**메타데이터 변환**을 누르면 선택한 데이터 폴더 안에 `metadata` 폴더가 만들어지고, 그 안에 세 파일이 저장됩니다. 다시 변환하면 새 파일로 바뀝니다.

| 파일 | 내용 |
|------|------|
| `<데이터셋 ID>.jsonld` | 메타데이터(데이터 설명서) (예: `MAX_SECOM_DS01.jsonld`) |
| `제조데이터검증확인서.pdf` | 기본정보, 폴더별 파일 수·용량, 데이터 규모, 검사 결과를 담은 A4 한 장짜리 확인서 |
| `<데이터셋 ID>.xlsx` | 요약 엑셀. 1행 항목명 + 2행 값으로, 입력 화면의 모든 칸과 폴더별 파일 수·용량(byte)·확장자, 총 샘플 수가 옆으로 이어집니다. 항목명 칸의 **배경색으로 시트(기본정보·데이터 정보 …)를 구분**하고, 색 안내는 `색 안내` 시트에 있습니다. |

- 확인서 번호와 직인 칸은 비워서 발급됩니다.
- 확인서 PDF를 열어 둔 채로 변환하면 저장되지 않습니다. PDF를 닫고 다시 누르세요.
